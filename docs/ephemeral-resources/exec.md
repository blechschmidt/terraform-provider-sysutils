# sysutils_exec (Ephemeral Resource)

Runs a command and returns its exit code, standard output and standard error without storing them in the plan or the state. Use it to fetch a secret from a password manager, vault CLI or key file and pass it to write-only arguments such as `content_wo` of the `sysutils_file` resource. The command runs whenever Terraform opens the ephemeral resource, which is during every plan and apply that needs it, so it must be safe to run repeatedly and should not change anything. It runs on the host, as the provider's user, also when the provider's `root_dir` is set.

An [ephemeral resource](https://developer.hashicorp.com/terraform/language/resources/ephemeral) needs Terraform 1.10 or later, or OpenTofu 1.11 or later. Its values can only be used where Terraform guarantees that they are not stored: in [write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) such as `content_wo` of [`sysutils_file`](../resources/file.md) (Terraform 1.11 or later, OpenTofu 1.11 or later), in provider configuration, in locals and ephemeral variables and outputs, and in provisioners. Terraform rejects them in ordinary resource arguments.

Unlike the [`sysutils_exec` resource](../resources/exec.md), which runs its command once and records the output in the state, this runs the command whenever Terraform needs the value: during every plan and every apply that uses it, and not at all in runs that don't. Use it for commands that only read, such as fetching a secret from a password manager or a vault, or decrypting a file; use the resource for commands that change something.

## Example Usage

### Fetch a token from a secret store

```terraform
# Needs Terraform 1.11 or later, or OpenTofu 1.11 or later, to pass the
# value to a write-only argument. The command runs during every plan and
# apply that needs the value, so it must only read.
ephemeral "sysutils_exec" "api_token" {
  command = ["/usr/bin/vault", "kv", "get", "-field=token", "secret/app"]
  environment = {
    VAULT_ADDR = "https://vault.example.com:8200"
  }
  timeout = "30s"
}

# The token is never stored in the plan or the state. Increase
# content_wo_version to write a rotated token.
resource "sysutils_file" "api_token" {
  path               = "/etc/app/token"
  content_wo         = trimspace(ephemeral.sysutils_exec.api_token.stdout)
  content_wo_version = 1
  mode               = "0600"
}
```

### Decrypt a file passed on standard input

```terraform
# Decrypt a secret kept next to the configuration. The ciphertext is sent
# on standard input; the plaintext exists only in memory.
ephemeral "sysutils_exec" "decrypt" {
  command = ["/usr/bin/age", "--decrypt", "--identity", "/root/.config/age/key.txt"]
  stdin   = file("${path.module}/secrets/db.env.age")
}

resource "sysutils_file" "db_env" {
  path               = "/etc/app/db.env"
  content_wo         = ephemeral.sysutils_exec.decrypt.stdout
  content_wo_version = 1
  mode               = "0600"
}
```

## Schema

### Required

- `command` (List of String) Command and arguments as a list. Element `0` is the executable, looked up in `PATH` if it contains no slash. Example: `["/bin/sh", "-c", "pass show app/token"]`.

### Optional

- `environment` (Map of String) Environment variables to pass to the command. If `inherit_parent_environment` is `false`, these are the only variables in its environment.
- `fail_on_nonzero` (Boolean) If `true` (default), a non-zero exit code fails the operation. The diagnostic quotes the beginning of standard error, never standard output. If `false`, the exit code is returned in `exit_code`.
- `inherit_parent_environment` (Boolean) If `true` (default), the command starts from the Terraform provider's environment and the keys in `environment` override specific values. If `false`, only the `environment` map is used.
- `max_output_bytes` (Number) Maximum number of bytes of standard output, and separately of standard error, to accept. Defaults to `1048576` (1 MiB); at most `16777216` (16 MiB). More output is an error rather than being truncated, so that a secret is never silently cut short.
- `stdin` (String) Data to pipe into the command's standard input.
- `timeout` (String) Maximum run time, as a Go duration string such as `"30s"` or `"2m"`. Defaults to `"5m"`. When it expires, the command's whole process group is killed with `SIGKILL` and the operation fails, regardless of `fail_on_nonzero`.
- `working_directory` (String) Working directory of the command. Defaults to the provider's working directory.

### Read-Only

- `exit_code` (Number) Exit code of the command.
- `stderr` (String, Sensitive) Standard error, verbatim. Bytes that are not valid UTF-8 are replaced by U+FFFD.
- `stdout` (String, Sensitive) Standard output, verbatim (use `trimspace()` to drop a trailing newline). Bytes that are not valid UTF-8 are replaced by U+FFFD.

## Output and errors

`stdout` and `stderr` are the complete output of the command. More than `max_output_bytes` (1 MiB by default) on either stream is an error, not a truncated value, so that a secret is never silently cut short and written somewhere half-complete. Neither is ever stored in the plan or the state, and both are sensitive, so Terraform redacts anything derived from them.

A non-zero exit fails the operation with `Command exited with non-zero status`, unless `fail_on_nonzero = false`, in which case the exit code is in `exit_code`. Failure diagnostics, which end up in CI logs, never contain standard output, which is where commands usually print secrets; they quote up to 4 KiB of standard error. Don't let the command print secrets to standard error.

The command runs in its own process group, like that of the `sysutils_exec` resource. When `timeout` (5 minutes by default) expires, or Terraform is interrupted, the whole group is killed with `SIGKILL`, and the operation fails with `Command timed out`. The command counts as finished once every process holding its standard output or standard error has closed them; background processes that keep them open for more than 5 seconds after the command exits make it fail.

## Caveats

- The command runs with the privileges and, unless `inherit_parent_environment = false`, the environment of the user running Terraform, on the host, even when the provider's `root_dir` is set. Treat it like a shell script run as that user.
- Its configuration (`command`, `environment`, `stdin`) is not stored in the state either, so a secret passed to the command, for example in `environment`, stays out of the state as well.
- Terraform cannot tell when the output changes. To write a changed secret with `content_wo`, increase `content_wo_version`.
- Invalid UTF-8 in the output is replaced by U+FFFD, since Terraform strings are UTF-8. For binary output, have the command encode it, for example with `base64`, and decode it with `base64decode()`.
- OpenTofu 1.13.0 plans and applies configurations with ephemeral resources, but `tofu show -json` of a saved plan fails with "no schema found for ephemeral...". Tools that read plans as JSON, such as policy checks, need another OpenTofu version.
